# SCENE GATE

**Status:** GOVERNED — operational (Phase 1, 2026-07-20). A pass/fail test applied to every scene
**before writing** (design half) and **before commit** (draft half). It tests the scene; it never
prescribes its plot. A failed check means: fix, or get Mert's explicit waiver — never write around it.

## A. Pre-write (design)

- [ ] Mert has authorized this scene (approved arc map or direct instruction).
- [ ] Every BLANK brief field this scene would need is either filled by Mert or the scene is
      redesigned to not need it. **No blank is filled by inference.**
- [ ] Location is visually establishable in ≤2 concrete lines (if not: island/set design is
      missing — stop and ask).
- [ ] Characters physically present are listed; each has a runtime card
      (`docs/runtime/CHARACTER_RUNTIME_CARDS.md`) with enough authored voice to write them.
- [ ] Someone on stage has an immediate, visible objective.
- [ ] The scene contains at least one planned interruption, reversal, or intrusion (something that
      breaks the expected flow).
- [ ] A prop or environmental interaction is identified where useful.
- [ ] Something is deliberately withheld (information the scene knows and does not say).
- [ ] The scene ends with a material change (state, relationship, information, position — not just
      mood).
- [ ] If it has a choice node: axis identified; each option is a concrete action in the
      protagonist's voice; each option's downstream difference is at least one **event**, not an
      adjective; no fake branch (options that reconverge with no persistent difference).
- [ ] If a fight: `FIGHT_DIRECTION.md` checklist passes and a locked FIGHT_BRIEF exists.
- [ ] If any canon character/event appears: a locked CANON_ENCOUNTER_BRIEF covers it.

## B. Pre-commit (draft)

- [ ] Storyboard test: every action block is drawable without asking the author questions.
- [ ] Name-tag test: dialogue attributable with tags removed.
- [ ] Narrator ≤ ~10% of words; card/transition/closer only; zero jokes, zero theme or feeling
      explanation, zero significance announcements.
- [ ] No pattern from `ANTI_CLAUDEISM.md` (spot-check the 12).
- [ ] No internal monologue unless this scene carries a Mert-approved interiority note.
- [ ] Word count within the approved 800–1,000 target (or a recorded reason).
- [ ] State operations live in the sidecar/annotation layer, named as events, using
      `STORY_ENGINE.md` vocabulary — **no production metadata, proposals, or notes inside the
      playable prose.**
- [ ] No invented names/entities beyond the incidental-extras license; anything recurring is
      flagged for Mert.
- [ ] Scene registered with a single valid status; cross-references resolve.
